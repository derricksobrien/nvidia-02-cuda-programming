# CUDA Programming Essentials

> **Track:** NVIDIA HPC & Developer Upskilling (Track 2)
> **Course 2 of 8**

Write, optimize, and debug GPU kernels with CUDA for high-throughput parallel computation.

---

## Modules

### Module 1: GPU Threading Model & Blocks

**Learning Objectives:**
- Explain grids, blocks, and threads
- Assign thread indices correctly
- Avoid thread divergence

### Module 2: Memory Management

**Learning Objectives:**
- Allocate and free device memory
- Use shared memory for fast access
- Minimize host-device data transfers

### Module 3: Kernel Writing & Optimization

**Learning Objectives:**
- Write and launch basic kernels
- Apply loop unrolling and tiling
- Achieve >80% occupancy

### Module 4: Debugging with Nsight

**Learning Objectives:**
- Profile kernels with Nsight Compute
- Find memory access bottlenecks
- Interpret warp efficiency metrics

### Module 5: CUDA Libraries

**Learning Objectives:**
- Use cuBLAS for matrix operations
- Apply cuDNN for deep learning layers
- Integrate cuFFT for signal processing
